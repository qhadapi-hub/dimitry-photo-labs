Getting startedCara memulai

Once publicly available, install the plugin in ChatGPT, invoke Dimitry Photo Labs, upload an original photo, choose a Lab, adjust its controls and explicitly apply the edit. Navigation alone does not edit photos.Setelah tersedia untuk publik, instal plugin di ChatGPT, panggil Dimitry Photo Labs, unggah foto asli, pilih Lab, atur kontrol dan tekan Terapkan. Navigasi saja tidak mengedit foto.

The panel does not appearPanel tidak muncul

Invoke the plugin again or type “Buka Relight” for the lighting panel. Rendering can vary across clients. Report your device and client version if it persists.Panggil kembali plugin atau ketik “Buka Relight” untuk panel pencahayaan. Tampilan dapat berbeda antar aplikasi ChatGPT. Laporkan perangkat dan versi aplikasi bila berlanjut.

The photo looks differentFoto terlihat berbeda

Keep the original and review faces, objects and composition at full size. If unauthorized changes occur, request a revision from the original with narrower scope. Exact pixel preservation is not guaranteed.Simpan foto asli dan periksa wajah, objek serta komposisi dalam ukuran penuh. Jika terjadi perubahan yang tidak diminta, minta revisi dari asli dengan lingkup lebih sempit. Preservasi piksel identik tidak dijamin.
